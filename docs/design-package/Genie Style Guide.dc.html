01 — PRINCIPLES

What makes it Ledger

FIRM, NOT SOFT
Square-ish corners
Radii stay between 0 and 3px. Corners read as cut, not rounded. Pills are reserved for toggles only.
HAIRLINE STRUCTURE
1px keylines, not shadows
Structure comes from thin rules. Shadows appear only on lifted surfaces — dialogs, toasts, dropdowns.
DATA WEARS MONO
Labels in Geist Mono
Eyebrows, statuses, counts, IDs and timestamps are uppercase mono with wide tracking — the "ledger" signal.
COLOR IS MEANING
Blue = primary & selection only
Brand blue marks the primary action and current selection. Every other color is semantic — success, warning, error. No decoration.
NO GRADIENTS NO EMOJI NO DECORATIVE CIRCLES MOBILE-FIRST

03 — TYPOGRAPHY

Two families, three roles

DISPLAY · GEIST
Geist
Headlines & numbers. Weight 800, tight tracking (-.02em).
UI / BODY · GEIST
Geist
Everything interactive & prose. Weights 400–700. Same family as display — one typeface carries both roles by weight.
DATA / LABELS · GEIST MONO
Geist Mono
Eyebrows, status, IDs, timestamps, counts. Uppercase, tracked .06–.14em.

Driven by three base knobs — heading, body, label — with every role a fixed ratio off its group base. Each breakpoint sets just 3 numbers. Tokens that share a value (display = h2, h3 = title, sm = xs) keep separate names only for semantic clarity in markup; never add an in-between size. Every role steps at the same breakpoints, so nothing stays frozen tiny while neighbours grow.
SIGNATURE PATTERN
The mono eyebrow
Status moments lead with a tracked mono label — often prefixed with a ● status dot — sitting above a Geist headline. It replaces decorative icons entirely.
03B — RESPONSIVE

Stepped scaling, mobile → 4K

Type and layout step together at eight breakpoints (Tailwind-style — sizes jump at each tier and hold between, rather than scaling fluidly). Both the type tokens and the container/sidebar widths are redefined at each tier, so a screen never has big headings next to a stranded narrow column or frozen tiny labels.
