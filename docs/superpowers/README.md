# Historical design specs and implementation plans

The dated files in `specs/` and `plans/` capture decisions and proposed work from earlier development sessions. Commands, credentials used in local examples, package versions, test counts, file paths and checkboxes describe that time; they are not current setup instructions or evidence of completion. Do not use example passwords for deployment.

Use the [repository README](../../README.md) for local setup, [deployment guide](../deployment.md) for the current runtime contract, and Beads (`bd`) for task status and remaining work. The [design package](../design-package/index.md) remains the screen reference; compare its implementation reference with current code when changing components.
